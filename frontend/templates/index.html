API REFERENCE

Connecter le scoring

Les mêmes résultats sont disponibles pour une intégration externe.

Flask · JSON · localhost:5000
GET/health

État de l’application et présence du modèle.

GET/model/info

Version, seuil, features et métriques.

POST/predict

Score individuel avec drivers SHAP.

POST/predict/batch

Score de plusieurs clients en une requête.

GET/metrics

Benchmark des modèles et métriques du test.

Example request

POST /predict
curl http://127.0.0.1:5000/predict \
  -H "Content-Type: application/json" \
  -d '{
    "Contract": "Month-to-month",
    "MonthlyCharges": 89.5,
    "TotalCharges": 716.0
  }'
La réponse contient churn_probability, risk_level, retention_priority et recommended_action.
