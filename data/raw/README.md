# Donnée brute

Le fichier attendu est `Telco-Customer-Churn.csv`.

Source utilisée pour ce projet : IBM, dépôt public `IBM/telco-customer-churn-on-icp4d`,
fichier `data/Telco-Customer-Churn.csv`.

URL : https://raw.githubusercontent.com/IBM/telco-customer-churn-on-icp4d/master/data/Telco-Customer-Churn.csv

Le fichier n'est pas versionné dans Git. Utilisez `python scripts/download_data.py` pour le
récupérer, puis `python scripts/run_pipeline.py` pour produire les artefacts.
